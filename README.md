# 旅途手账 · AI 旅行攻略生成器

AI 驱动的旅行攻略生成工具，支持：
- 🗺️ 智能行程规划
- 🚕 交通时间估算（公交、地铁、打车）
- ⏰ 时间自动分配与重新规划
- 📍 就近景点推荐
- 🏨 酒店价格查询
- 🔍 抖音 & 小红书搜索

## 使用方法

### 单文件版（推荐）
直接双击 `standalone.html` 在浏览器中打开即可，无需任何依赖。

### 开发版
需要以下三个文件在同一目录下：
- `index.html` - 页面结构
- `styles.css` - 样式表
- `app.js` - 业务逻辑

然后在浏览器中打开 `index.html`。

## 功能特性

1. **行程拖拽替换**：支持拖拽景点卡片替换
2. **添加行程**：点击添加按钮追加景点
3. **交通时间估算**：自动计算景点间公交/地铁/打车耗时
4. **时间重新分配**：添加/替换景点后自动均分停留时间
5. **就近推荐**：备选池中标注距离最近的「推荐较近」景点
6. **地图定位**：高德/腾讯地图一键定位
7. **酒店查询**：携程实时价格查询
8. **多设备同步**：支持 Git 版本控制，另一台电脑 `git pull` 即可同步
